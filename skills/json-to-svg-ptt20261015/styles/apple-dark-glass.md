# Apple 暗黑毛玻璃风（Dark Glassmorphism）

仅在选中本风格时读取。画布、内容忠实度和图片处理要求遵循 `SKILL.md` 的核心约束。

## 布局与层级

- 采用 Bento Grid，推荐卡片间距 `24px`，圆角 `18–24px`；布局随内容调整。
- 目录或六项概览页可采用顶部宽幅导引卡片（`1200 × 100`）与下方 `2 × 3` 网格。这是可选示例，不要求所有页面使用六张卡片。
- 单一焦点可使用 `1200 × 580` 大卡片；并列内容可使用 `2 × 2`、三栏、左右等宽或 `2:1` 分栏。
- 也可采用主卡片加两侧辅助卡片、顶部英雄卡片加下方网格，或不同尺寸的混合网格；最重要的信息占据最大的卡片。

## 背景与玻璃材质

用深空渐变、青紫环境微光与精密点阵建立背景层次；卡片采用半透明磨砂渐变、镜面高光细边框及景深投影。

| 元素 / SVG 标识 | 参数 |
|---|---|
| 深空底色 `bgGrad` | 径向渐变：`#172033`（0%）→ `#0d1322`（60%）→ `#070a12`（100%） |
| 环境微光 `glowCyan` / `glowPurple` | 左上与右下的大半径径向柔光圆，分别使用 `#38bdf8`、`#a855f7`，透明度从 `0.16–0.22` 渐变至 `0` |
| 精密点阵 `dotGrid` | `32 × 32` 的 `<pattern>`，圆点 `r="1" fill="#475569" opacity="0.28"` |
| 玻璃卡片 `cardGrad` | 线性渐变：`#1e293b`（`stop-opacity` 取 `0.72–0.78`）→ `#0f172a`（`stop-opacity` 取 `0.52–0.58`）；顶部叠加镜面高光细线 |
| 景深投影 | `<feDropShadow dx="0" dy="14" stdDeviation="16" flood-color="#020617" flood-opacity="0.55" />` |

参数范围用于选值，写入 SVG 属性时使用单个合法数值，不将范围字符串直接写入属性。

## 语义色板与矢量图形

| 色名 | 色值 |
|---|---|
| 天际蓝 | `#38bdf8` |
| 电光蓝 | `#60a5fa` |
| 极光紫 | `#c084fc` |
| 薄荷青 | `#2dd4bf` |
| 琥珀金 | `#fbbf24` |
| 珊瑚粉 | `#fb7185` |

- 按大纲中的实际主题建立颜色映射，同一主题跨页复用同一颜色；无需使用全部六色，也不预设章节数量或标题。
- 图标由内容语义决定，例如循环回路、转向路径、时间表盘、规则护盾、价值星芒或上升折线；统一线条、尺度与视觉重量。
- 图标用于辅助表达，不替代大纲指定的真实图片。

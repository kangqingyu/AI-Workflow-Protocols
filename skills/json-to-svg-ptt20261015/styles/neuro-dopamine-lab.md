# 风格八：神经多巴胺博弈与数字健康极简风（Neuro-Balance & Digital Minimalism Lab）

> 灵感源自 **Apple Health / Screen Time（数字健康卡片系统）**、**Oura Ring / Whoop（生物节律与神经遥测实验室）** 与 **Headspace（正念觉察与双极情绪光谱）**。采用护眼干净的**云母柔雾基底（`#F3F5F1`）+ 24px 生物遥测微点阵 + 冷暖双极弥散光晕**，通过**多巴胺冲动红橙（Dopamine Rose `#E11D48` / Impulse Amber `#EA580C`）**与**前额叶正念松翠（Prefrontal Teal `#0D9488` / Rule Indigo `#4F46E5`）**的冷暖双极博弈，搭配**心电/脑波双态波形（高频锯齿脉冲 vs 平滑正弦心流）、刺激阈值刻度格、4 级摩擦力阶梯条与数字健康标本底座**，打造兼具认知科学深度、量化自我（Quantified Self）秩序感与极简呼吸感的演示体验。

## 1. 色彩系统（Dual-Pole Neuro-Telemetry Palette）

### 1.1 云母柔雾遥测基底（Bio-Mica Telemetry Canvas）
- **画布底色**：全画布 `1280×720` 填充柔和护眼的云母灰白 `#F3F5F1`，叠加 `24px × 24px` 生物遥测圆点阵列（`r="1.1"`，`fill="#CBD5E1"`，`opacity="0.65"`）。
- **冷暖双极环境光晕（Dual-Pole Ambient Aura）**：
  - 左上/冲动侧：`radialGradient` `#F43F5E`（透明度 `0.10–0.12`）→ `#FB923C`（透明度 `0.05`）→ 透明，象征多巴胺触发源。
  - 右下/自控侧：`radialGradient` `#0D9488`（透明度 `0.12–0.14`）→ `#10B981`（透明度 `0.05`）→ 透明，象征前额叶正念与心流场。

### 1.2 双极语义四色（Core Semantic Poles）
- **极点 A1 · 多巴胺脉冲红（Dopamine Rose）**：`#E11D48` / `#F43F5E`（浅底 `#FFF1F2`，描边 `#FECDD3`）—— 标记上瘾触发、自动打开 APP、反弹、高强度刺激过载。
- **极点 A2 · 成瘾循环琥珀（Impulse Amber）**：`#EA580C` / `#D97706`（浅底 `#FFF7ED` / `#FFFBEB`，描边 `#FED7AA` / `#FDE68A`）—— 标记低行动成本、短期快感、注意力碎片化与时间损耗。
- **极点 B1 · 系统规则靛蓝（Rule & Friction Indigo）**：`#4F46E5` / `#0284C7`（浅底 `#EEF2FF` / `#F0F9FF`，描边 `#C7D2FE` / `#BAE6FD`）—— 标记设备隔离、使用时长记录、4 级摩擦力阶梯、工具拦截与请求规则（`DIRECT / REJECT`）。
- **极点 B2 · 前额叶松石翠（Prefrontal Flow Teal）**：`#0D9488` / `#059669`（浅底 `#F0FDFA` / `#ECFDF5`，描边 `#99F6E4` / `#A7F3D0`）—— 标记元认知觉察、阅读模块培养、树根深层需求、高价值替代活动与正向反馈训练。

### 1.3 卡片表面与深空聚焦舱（Card Surfaces）
- **纯白数字健康卡（Health Bento White）**：
  - 填充：`#FFFFFF`，圆角 `rx="22"`（子卡片 `rx="14"`），描边 `1.5px–2px`（语义浅色描边或 `#E2E8F0`）
  - 左侧或顶部嵌有 `6px–10px` 宽的圆角能量色条，直观标识卡片所属极点
  - 悬浮阴影：`feDropShadow dx="0" dy="8" stdDeviation="12" flood-color="#0F172A" flood-opacity="0.06"`
- **深空皮层聚焦舱（Cortex Slate Hero Card）**：
  - 填充：`#0F172A`（或 `#0F172A` → `#1E293B` → `#0F292E` 线性渐变），描边 `#1E293B` 或内嵌 `#334155` 细框
  - 文字配色：主标题纯白 `#FFFFFF`，多巴胺警示高亮 `#FDA4AF` / `#FCD34D`，前额叶心流高亮 `#5EEAD4` / `#34D399`

## 2. 字体与排版规范（Typography）

- **中文字体族**：`'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif`
- **英文与遥测数字字体族**：`'SF Pro Display', 'Inter', 'Helvetica Neue', monospace`
- **字号层级标准**：
  - **封面主标题**：`84px - 92px`，`font-weight="900"`，`#0F172A`
  - **顶部导航栏主标题**：`26px - 28px`，`font-weight="900"`，`#0F172A`
  - **卡片二级标题（`##`）**：`22px - 25px`，`font-weight="900"`
  - **卡片三级标题（`###`）与高亮结论**：`19px - 22px`，`font-weight="800"`
  - **正文与列表项**：`17px - 20px`，`font-weight="600"`（重点词句 `font-weight="800"` 并用对应极点色高亮）
  - **胶囊编号与页码标签**：`12px - 16px`，`font-weight="800"`，`letter-spacing="1.2"`

## 3. 标志性视觉组件（Signature Components）

### 3.1 顶部遥测导航栏（Top Bio-Telemetry Header Bar）
- 位于 `x="64" y="34" width="1152" height="64" rx="18"`，纯白底色配柔和阴影。
- **左端**：`44×44` 圆角状态方块（`rx="12"`，填充当前页主题极点色，如 `#E11D48`、`#EA580C`、`#0284C7`、`#4F46E5`、`#0D9488` 或 `#0F172A`），内部绘制纯白或青翠脉冲波/图标；右侧紧接页面主标题。
- **右端**：深空黑页码胶囊（`width="84" height="36" rx="12" fill="#0F172A"`），居中显示 `XX / 29`。

### 3.2 双态脑波与多巴胺刻度（Dual-Wave & Threshold Meters）
- **多巴胺高频锯齿波（Impulse Spike Wave）**：用折线 `<path d="M 0 18 L 28 18 L 36 4 L 44 32 L 52 8 L 60 26 L 68 18 L 96 18"/>` 表现情绪波动、冲动触发与刺激过载。
- **前额叶平滑正弦波（Prefrontal Sine Flow）**：用三次贝塞尔或二次曲线 `<path d="M 0 18 Q 24 4 48 18 T 96 18"/>` 表现专注、阅读心流与情绪平稳。
- **刺激阈值 / 摩擦力阶梯格（Segmented Level Pills）**：用 3 格或 4 格圆角小矩形（如 `24×14 rx="4"`）直观展示刺激递增（1/3 → 2/3 → 3/3）或打开难度递增（第 1 级主屏 → 第 4 级未安装）。

### 3.3 真实截图与模型图标本底座（CleanShot Telemetry Mounts）
- 涉及手机/电脑时间统计截图、拦截工具截图或理论模型图时：
  - 严禁裁剪或手绘替代原图，必须使用 Base64 Data URI `<image preserveAspectRatio="xMidYMid meet"/>` 完整内嵌。
  - 外层包裹带圆角与细描边的数字健康标本框（`rx="16"`，背景 `#F8FAFC` 或 `#0F172A`），顶部可搭配三色窗口圆点或极点色指示条，使多张不同比例的截图在同一页面内保持整齐划一的视觉秩序。

## 4. 页面类型设计范式（Slide Archetypes）

### 4.1 封面页（Cover）
- 左侧为大字号主标题、双极渐变分割标尺、带左侧松翠色条的副标题卡，以及底部「脉冲触发 → 规则屏障 → 正弦心流」三阶图形进度轨；右侧为深空黑**神经多巴胺博弈与心流转换舱**，展示高频脉冲环经由规则过滤门转化为同心正念波纹。

### 4.2 目录页（Table of Contents）
- 采用 **3×2 六宫格 Bento 矩阵**，6 张卡片沿光谱从「01 玫瑰红 → 02 琥珀橙 → 03 遥测天青 → 04 规则靛蓝 → 05 松石翠 → 06 深空黑+翠绿」依次递进，每张卡片右上角配有专属微缩矢量图标（四步循环环、三层阶梯、时钟仪表、拦截护盾、树根模型、神经网络节点）。

### 4.3 正文与图文混排页（Content & Telemetry Bento Grid）
- **核心结论横幅 + 下方多列分步卡**：顶部用 `#0F172A` 深空黑横幅提炼作者核心洞察，下方按 2 列、3 列或 2×2 网格展开对比与演进。
- **单图/双图/四图遥测展示页**：
  - 单图页（如《上瘾循环》《大脑模块说》《Tyme 主动记录》）：采用**左文右图**或**上文下图**黄金分割布局，让原图拥有充足展示面积。
  - 双图页（如《手机时间统计 1-2》《BlockSite 与 Session 拦截》）：采用上方提炼文字横幅 + 下方左右对称双图标本舱。
  - 四图页（如《电脑使用场景 1-4》）：采用上方 Timing 说明横幅 + 下方 **2×2 对称遥测图谱网格**，保证每张统计截图清晰可读。

# 圆角立体几何撞色（Soft 3D Clay & Geometric Color-Blocking）

仅在选中本风格时读取。画布、内容忠实度和图片处理要求遵循 `SKILL.md` 的核心约束。

## 布局与撞色层级

- 采用大圆角 Bento Grid，推荐卡片间距 `24–28px`，卡片圆角 `rx="28–36"`；按页面信息结构灵活选用左右主次分栏、顶部英雄卡加多栏柱状卡、`2 × 2` 对角网格或三段式布局。
- **撞色交替原则（Color-Blocking Rhythm）**：打破全屏单一半透明色块，采用**高饱和彩色立体主卡 × 温润羊皮白立体卡（内嵌高饱和 3D 几何岛屿）× 深海墨靛稳重卡**交替排布（如 `2 × 2` 网格采用对角撞色：`蓝 — 白×橙` / `白×绿 — 紫`），兼顾强视觉张力与阅读舒适度。
- 最核心论点或章节主卡使用高饱和主色块（配亮黄/纯白高对比强调块），并列细节或次级论证使用羊皮白立体卡承载深色正文。

## 画布背景与 4 层立体卡片结构

画布采用温暖工作室浅色基底与柔和彩色环境光晕；每张卡片由 **4 层立体结构** 复合而成，塑造柔光膨胀 3D 与实体键帽厚度感：

| 层级 / SVG 标识 | 参数规范 |
|---|---|
| 1. 工作室暖白画布 `canvasGrad` | 线性渐变：`#FAF6F0`（0%）→ `#F2ECE1`（55%）→ `#E6DEC8`（100%） |
| 2. 环境彩光 `ambient*` + 点阵 `dotGrid` | 左上与右下大半径径向柔光圆（取当前页主撞色，透明度 `0.12–0.15` 渐变至 `0`）；叠加 `36 × 36` 点阵（`r="1.5" fill="#B5AC9E" opacity="0.42"`） |
| 3. 彩色环境投影 `<feDropShadow>` | 随卡片色系匹配投影色：`dx="0" dy="14–18" stdDeviation="12–16" flood-opacity="0.22–0.30"` |
| 4. 3D 实体厚度底座（Extrusion Base） | 在主卡片同宽高、向下偏移 `dy="8–12"` 处先绘制底层实心圆角矩形，色值取主卡同色系深一阶暗部色 |
| 5. 膨化受光主面（Puffy Surface） | 线性渐变从左上亮面过渡至右下饱和深面，模拟 Soft Clay 体积受光 |
| 6. 顶部镜面倒角高光（Specular Rim） | 内缩 `2px` 的同圆角矩形描边：`fill="none" stroke="#FFFFFF" stroke-opacity="0.45–0.95" stroke-width="2–2.5"` |

## 撞色色板与 3D 几何母题

| 语义角色 / 色名 | 受光主面渐变（左上 → 右下） | 3D 实体底座色 | 适用场景与文字配色 |
|---|---|---|---|
| 电光克莱因蓝（Cobalt） | `#4F6FFF` → `#3653F5` → `#223AD8` | `#17279E` | 核心主卡、预测/架构主题；配纯白 `#FFFFFF` 与柠檬黄 `#FFD43B` 文字 |
| 活力暖阳橙（Tangerine） | `#FF8352` → `#FF622E` → `#E04312` | `#B53008` | 重点撞色卡、行为/目标主题；配纯白 `#FFFFFF` 与浅黄 `#FFF3B0` 文字 |
| 翡翠薄荷绿（Emerald Mint） | `#2CE0A2` → `#10B981` → `#047857` | `#045940` | 演进/增长/安全主题；配纯白文字或柠檬黄高亮框 |
| 极光紫罗兰（Vivid Violet） | `#9061F9` → `#7538EC` → `#581DD4` | `#3E1299` | 工具/连接/高阶能力主题；配纯白与柠檬黄文字 |
| 珊瑚警示红（Coral Rose） | `#FF6B84` → `#F23D5C` → `#CC1B3B` | `#991029` | 失效模式/警示焦点主卡；配纯白文字与立体黄底胶囊框 |
| 深海墨靛（Ink Navy） | `#252C48` → `#141829` | `#0B0E18` | 顶部横幅、底部总结桥接卡或 3D 几何底座；稳住高饱和撞色重心 |
| 温润羊皮白（Warm Clay） | `#FFFFFF` → `#F6F0E6` | `#CFC6B8` | 高可读性并列内容卡；正文用深墨色 `#181C2A`，重点词用主题色高亮 |

### 3D 立体几何组件（Volumetric Primitives）

- 淘汰单薄细线图标，使用偏心径向渐变（`cx="32%" cy="28%" r="68%" fx="28%" fy="24%"`）与多层偏移圆角块组合绘制 **Soft 3D 几何组件**：
  - **立体球体（3D Clay Sphere）**：柠檬黄（`#FFF3B0` → `#FFD43B` → `#C97A00`）、青蓝（`#CFFAFE` → `#22D3EE` → `#0284C7`）、珊瑚粉（`#FFC2CD` → `#FF5C77` → `#B81835`）。
  - **立体键帽底座（3D Keycap Island）**：羊皮白卡片内的图标统一置于带 `5–6px` 实体厚度底座的高饱和圆角方体（`88×88` 或 `100×100`，`rx="24–28"`）之上。
  - **阶梯胶囊柱与圆环（Stepped Cylinders & Torus）**：根据页面语义组合出概率波峰、快慢双轨圆环、Scaling 阶梯柱、AST 树节点或工具互锁环。
- 卡片内部装饰圆环如靠近边缘，应使用 `<clipPath>` 裁剪在卡片圆角矩形内，确保边界干净利落。

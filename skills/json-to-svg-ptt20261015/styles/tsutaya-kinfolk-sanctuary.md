# 风格九：蔦屋书店森系呼吸感与现代策展书卷风（Tsutaya & Kinfolk Mindful Reading Sanctuary）

## 1. 风格定位与美学灵感

- **核心气质**：自然呼吸感（Effortless Breathing）、森林书店光影策展（Forest Bookshop Curation）、温润和纸与文库本装帧（Washi & Bunko Bookcraft）、智性松弛感（Mindful Intellectual Flow）。
- **设计灵感**：
  - **代官山蔦屋书店（Daikanyama T-SITE / Tsutaya Books）**：森林绿意透过木质百叶窗洒在纯白与暖米色书架上的自然光影，兼具现代极简秩序与人文温度。
  - **《Kinfolk》与《Brutus》读书特辑**：开阔的呼吸感留白、温润的再生特种纸张、克制的衬线标题与现代无衬线正文的混排美学。
  - **日本新潮/岩波文库本（Bunko Bookbinding）**：精巧的书脊装订线（Book Spine）、天顶垂下的 V 字分叉丝带书签（Bookmark Ribbon）、藏书票印章（Ex-Libris Seal）与半透明荧光笔读书批注（Marginalia Highlight）。
- **适用场景**：阅读方法论、经典书单策展、终身学习与认知升级、人文哲学、生活方式与心流习惯养成。

## 3. 排版与字体规范

- **衬线标题与引文体（Editorial Serif）**：
  - `font-family: 'Songti SC', 'STSong', 'Noto Serif CJK SC', 'Georgia', serif`
  - 用于：封面大标题、每页 H1 主标题、书名高亮、名人语录、藏书票衬线编号。
- **现代无衬线正文体（Clean Sans-Serif）**：
  - `font-family: 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', system-ui, sans-serif`
  - 用于：卡片小标题、正文要点列表、图表标签，保证多字数页面的极佳清晰度。
- **等宽索书号与数据体（Catalog Monospace）**：
  - `font-family: 'JetBrains Mono', 'SF Mono', 'Menlo', monospace`
  - 用于：顶部索书号（如 `EX-LIBRIS // CH.01`）、页码、百分比数据（`68%`、`15%`、`85%`）。
- **字号层级约束**：
  - 页面主标题：`28px–32px`（字重 `700–800`）
  - 核心主张横幅文字：`19px–22px`（字重 `700`）
  - 卡片标题（H2）：`19px–22px`（字重 `700`）
  - 卡片子标题（H3）：`16px–18px`（字重 `700`）
  - 卡片正文列表：`15px–17px`（字重 `500`，行距 `26px–32px`）

## 4. 标志性视觉组件（Signature Components）

### 4.1 立体书脊 Bento 卡片（Book-Spine Bento Card）
- 每张核心 Bento 卡片左侧带有 `10px–14px` 宽的**精装书脊装订条（Book Spine Strip）**，填充 `#2A6B53`、`#B57B35`、`#C24E3A` 或 `#3B627A`，并在书脊上下两端绘制 2 道浅金色装订竹节横线（`stroke="rgba(255,255,255,0.55)"`）。
- 卡片圆角左小右大或统一 `rx="14"`，外层配温暖柔和的纸张投影（`dx="0" dy="8" stdDeviation="12" flood-color="#16241D" flood-opacity="0.06"`）。

### 4.2 文库本天顶分叉丝带书签（Bunko Bookmark Ribbon）
- 在每页最关键的卡片或顶部横幅右上角，绘制一枚垂下的 **V 字分叉丝带书签**：
  - 例如：`M x,y L x+22,y L x+22,y+36 L x+11,y+28 L x,y+36 Z`，填充 `#C24E3A`（朱砂红）或 `#B57B35`（藏书票金）。

### 4.3 半透明荧光笔读书批注（Marginalia Highlighter Band）
- 对正文中的加粗金句或核心概念，在其文字下方衬托一条半透明圆角荧光笔高亮带（高度 `10px–14px`，位于文字基线附近，颜色如 `#E8C574` 透明度 `0.35` 或 `#7DBA98` 透明度 `0.28`），营造真实翻阅纸质书划线批注的亲切感。

### 4.4 呼吸节律波纹与森林叶影（Mindful Breath Ripples & Dappled Light）
- 画布背景右上角或左下角配置 3–4 圈极淡的同心呼吸波纹圆环（`stroke="#2A6B53" stroke-opacity="0.08" stroke-dasharray="6 6"`），呼应「让读书像呼吸一样轻松」的主题。
- 页眉与页脚采用**代官山蔦屋书店展签（Curated Shelf Tag）**样式：左上角**只展示单行页面主标题（`title`）**（配左侧 `6px` 宽松石绿书脊竖条，**严禁在主标题上方再重复输出一行 `part_title` 小字**，避免出现“第一行小字、第二行大字”的重复标题），右侧为页码刻度。

## 5. 页面布局与核心红线

1. **画布尺寸固定**：`viewBox="0 0 1280 720" width="1280" height="720"`。
2. **文字完整性**：严格保留 JSON 大纲中的全部正文文字与层级结构，不遗漏任何要点，也不凭空编造大纲外的解释文字。
3. **Bento 网格间距**：卡片间距不少于 `20px`，四周安全边距不少于 `48px`（推荐左右边距 `56px`）。
4. **书单页专属优化**：当页面包含大量书名与问题分类时，采用**「主题书架策展格（Curated Bookshelf Grid）」**，将不同领域的书单分装在带书脊色标的独立卡片中，清晰易读、绝不拥挤或溢出。
5. **真实图片内嵌**：遇到图片提示指令时，将其转化为带**特种纸衬底相框（Archival Photo Mount）**的真实 Base64 Data URI `<image>`，不把图片提示语当作正文输出。

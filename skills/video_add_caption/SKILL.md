# 剪映自动字幕与导出

使用剪映专业版完成本地视频字幕制作，保留可编辑草稿。根据当前运行环境选择对应的 Computer Use 操作方式；不通过脚本直接修改剪映草稿文件或用其他视频工具替代剪映。

## 运行环境分流（ChatGPT vs Antigravity）

### A. ChatGPT / Codex 环境（具备内置 `cua_repl` 工具）
- **保持原方式不变**：直接使用内置 `cua_repl` 工具操作应用（调用 `cua.listApps()`、`getAXState()`、`setValue` / `paste`、截图及坐标点击）。

### B. Antigravity 环境（无内置 `cua_repl` 工具）
- **核心原则 1（固定流程极速化：单进程流水线代替逐轮交互）**：
  - 剪映「新建草稿 → 导入视频入轨 → 智能识别字幕 → 展开预设样式并套用黄底黑字 → 导出 `_字幕版.mp4`」全流程完全固定。
  - 在 Antigravity 下，**严禁**一步一截图、一步一轮 LLM 往返；**必须直接执行单进程极速流水线 `auto-caption`**（默认在标准沙盒 `BypassSandbox: false` 下运行，无需权限审批，将原本 25~30 次跨进程调用压缩为 1 次命令调用，UI 操作耗时仅数秒）：
    - `python3 -u /Users/kqy/.gemini/config/skills/video_add_caption/scripts/mac_cua.py auto-caption "<源视频绝对路径>" --verify-dir "<校验截图输出目录>"`
- **核心原则 2（“黄底黑字”预设样式快速定位法则：微滚即停 + 先点底部中央 `▼` 展开第三行）**：
  - **避坑要点**：右侧「文本 → 基础」面板中的「预设样式」初始默认处于**折叠状态**，仅显示第 1 行和半截第 2 行，**位于第 3 行第 1 个的“黄底黑字”默认是隐藏的**。切勿大幅向下滚动寻找，否则会直接滚过「预设样式」进入下方的「混合 / 描边 / 背景 / 发光 / 阴影」，导致无论怎么滚动都看不到“黄底黑字”。
  - **标准三步动作**：
    1. **微滚即停**：选中时间线字幕后，「预设样式」标题就在右侧面板中下部（初始 `y ≈ 480~580`），只需向下轻滚 **1~2 格**（让 `value="预设样式"` 标题停在 `y ≈ 320~430`）立即停止滚动；若不小心滚过头（`y < 320`），向上回滚即可。
    2. **点击底部正中央 `▼` 展开箭头**：展开按钮不在标题栏右侧，而在「预设样式」两行网格**底部正中央**（逻辑坐标约为 `(1513.5, 预设样式标题Y + 114)`，约 `(1513.5, 505)`，悬停提示为「展开」）。单击一次该 `▼` 箭头即可展开隐藏的第 3 行。
    3. **直取第三行第一个（最左侧）**：展开后，**第 3 行第 1 列（Row 3, Col 1）**即为目标「黄底黑字」预设（亮黄色实心底 + 黑色 `T`，对应无障碍树第 17 个 `automationstyleIconRepeaterItem`，即 `index 16`，坐标约为 `(1340, 预设样式标题Y + 144)`）。
- **核心原则 3（修改剪映项目名称 + 导出文件名双重统一为 `<源文件名>_字幕版`）**：
  - **步骤 A（新建草稿后立即修改剪映项目名称）**：
    1. 新建空白草稿进入编辑器界面后，剪映顶部标题栏正中央（逻辑坐标 `(864, 51)`）默认显示日期名称（如 `10月25日 (6)`）。
    2. **直接单击顶部正中央 `(864, 51)`**，剪映会自动全选该默认项目名称；随后按一次 `Delete`，通过 `type_unicode` 输入 `<源文件名去扩展名>_字幕版`（如 `209_字幕版`）并按 `Return` 回车确认。
    3. 修改项目名称后，不仅剪映草稿列表中保存的项目名规范统一，而且后续打开「导出」弹窗时，导出标题也会**自动默认继承该项目名**（`<源文件名>_字幕版`）。
  - **步骤 B（导出弹窗标题闭环校验与兜底清空）**：
    1. 打开右上角「导出」弹窗后，先读取 `ExportPathInput` 下方的完整输出路径节点（`desc` 形如 `/.../<源文件名>_字幕版.mp4`）。若已匹配 `/<源文件名>_字幕版.mp4`，直接点击导出即可。
    2. 若不匹配（例如未提前改项目名或存在后缀），**严禁在 `ExportDialog` 内使用 `mouse_drag` 拖选**（会拖动整个无边框导出窗口导致点击脱靶）；直接单击 `ExportFileNameInput` 中心点 `(1080, 316)`，连续发送 **25 次 `Delete`（退格键）** 彻底清空原名，再通过 `type_unicode` 输入 `<源文件名>_字幕版` 并闭环核对路径节点。
- **核心原则 4（遇到上一个项目时，必须先关闭上一个项目窗口，再新建继续）**：
  - **避坑要点**：切勿使用顶部菜单栏「文件 → 新建草稿」（既容易误点「关于剪映专业版」，又会额外弹出「是否确认新建草稿？」二次确认框阻塞流程）。
  - **标准三步动作**：
    1. 若上一条视频停留在「导出成功」弹窗（`ExportDialog`），先点击其关闭按钮 `automationcloseBtn`。
    2. **先关闭上一个项目窗口**：通过无障碍树找到编辑器主窗口 `AXStandardWindow` 的 `AXCloseButton` 执行 `AXPress`（或点击左上角红色关闭按钮 `(20, 51)`），剪映会自动保存当前草稿并直接退回剪映首页（无二次确认弹窗）。
    3. **在首页点击「开始创作」**：等待首页 `HomePageStartProjectDesp`（约 `(983, 306.5)`）出现后单击「开始创作」，进入全新空白草稿再继续导入下一条视频。
- **分步调试 / 自定义微调指令**（底层由 [scripts/mac_cua.py](scripts/mac_cua.py) 与 [scripts/jianying_flow.py](scripts/jianying_flow.py) 提供，与 `cua_repl` 1:1 等价）：
  - **列出/激活应用**（对应 `cua.listApps()` 与连接应用）：
    - `python3 /Users/kqy/.gemini/config/skills/video_add_caption/scripts/mac_cua.py list-apps`
    - `python3 /Users/kqy/.gemini/config/skills/video_add_caption/scripts/mac_cua.py activate`
  - **读取无障碍树**（对应 `getAXState()`）：
    - `python3 /Users/kqy/.gemini/config/skills/video_add_caption/scripts/mac_cua.py ax-state --depth 10`（可加 `--filter 关键词` 或 `--head N`；输出包含每个元素的逻辑坐标 `rect=(x,y,w,h)` 与中心点 `center=(cx,cy)`）
  - **1:1 逻辑坐标截图**（配合 `read_file` 视觉确认）：
    - `python3 /Users/kqy/.gemini/config/skills/video_add_caption/scripts/mac_cua.py screenshot <截图保存路径.png>`（自动将 Retina 截图缩放到与屏幕逻辑点 `1:1` 对齐，图片像素 `(x, y)` 直接等于点击坐标 `(x, y)`；支持 `--rect x,y,w,h` 局部截图）
  - **鼠标、滚轮与键盘输入**：
    - 点击：`click <x> <y>`、`double-click <x> <y>`、`right-click <x> <y>`
    - 拖放：`drag <x1> <y1> <x2> <y2>`
    - 滚动：`scroll <x> <y> <dy>`（`dy` 为负数时向下滚动）
    - 快捷键：`key cmd+shift+g`、`key return`、`key space`、`key escape`
    - 中文路径/文本输入（对应 `setValue` / `paste`）：脚本内置 `type_unicode`（基于 `CGEventKeyboardSetUnicodeString` 直接注入 UTF-16 字符，不依赖系统剪贴板，完全兼容标准沙盒与模态文件选择器）及 `paste "<路径或文本>"`。

## 输入与默认值

- 必需：源视频的本地绝对路径。沿用当前对话已经提供的文件，不要把示例文件当作本次输入。
- 样式：默认使用本流程的黄底黑字预设；用户指定其他样式时按其要求执行。
- 导出：用户要求完整复用本流程时包含导出；如果只要求制作字幕或明确暂不导出，则停在可编辑草稿。
- 项目名称与导出文件名：默认统一命名为 `<源文件名去扩展名>_字幕版`（导出文件为 `<源文件名去扩展名>_字幕版.mp4`，所在目录与源视频一致）。用户提供的路径或文件名优先。
- 示例：`/目录/a303.mp4` → 剪映项目名 `a303_字幕版`，导出文件 `/目录/a303_字幕版.mp4`。

## 1. 连接剪映与修改项目名称

遵循当前 Computer Use 工具返回的初始化说明（ChatGPT 使用 `cua_repl`；Antigravity 使用 `mac_cua.py`），再执行 UI 操作。

1. 尝试通过应用显示名称获取剪映专业版。
2. 名称解析失败时，通过 `cua.listApps()`（Antigravity 下使用 `mac_cua.py list-apps` / `activate`）获取真实应用标识。
3. 如果 bundle ID 对应多个辅助进程，改用已返回的主应用完整路径；本次环境验证过的路径是 `/Applications/VideoFusion-macOS.app`，bundle ID 是 `com.lemon.lvpro`。其他机器以实际发现结果为准。
4. 查看当前窗口，建立独立草稿；若上一个项目仍打开，先关闭上一个项目窗口回到首页，点击「开始创作」进入新建空白草稿，不要无意修改用户正在编辑的其他项目。
5. **修改剪映项目名称（与导出文件名保持一致）**：进入新建草稿后，单击编辑器窗口顶部正中央的项目名称区域（如默认的 `10月25日 (6)`，坐标约 `(864, 51)`，单击后会自动全选），按 `Delete` 清空后输入 `<源文件名去扩展名>_字幕版` 并按 `Return` 确认保存。

## 2. 导入并加入时间线

1. 在首页选择「开始创作」，在素材页选择「导入」。
2. 在系统文件选择器使用 `super+shift+g` 打开「前往文件夹」。
3. 输入源视频绝对路径。中文路径优先使用 `setValue` 或 `paste`（Antigravity 下使用 `mac_cua.py paste "<绝对路径>"`）；本次操作中 `typeText` 曾漏掉中文。提交前核对字段内容。
4. 在文件选择器确认选中的文件名与路径，再点击「导入」。
5. 将视频素材拖入主视频轨道，并验证轨道出现素材、总时长正确。素材库中出现缩略图不等于已加入时间线。
6. 拖放未生效时，可使用素材右键菜单「根据选中素材新建时间线」。这条备用路径在本次环境有效；切换后确认活动时间线确实包含视频。

## 3. 自动生成字幕

1. 打开顶部「字幕」→「智能识别」→「识别字幕」。
2. 源语言默认保留「自动检测语言」，除非用户指定语言。
3. 不额外启用翻译、智能划重点、智能去水词等选项。
4. 点击「开始识别」，观察识别进度并等待完成。识别正在进行时不要重复提交。
5. 完成后确认字幕轨道已经生成。新识别字幕默认是白色，直接进入第 4 节选择黄底黑字预设；不先播放、暂停或查找白色字幕来验证默认样式。等待识别完成后再操作样式，不在识别进度弹窗中点击。

## 4. 统一黄底黑字样式

按「识别完成 → 选中时间线字幕 → 全部字幕 → 预设样式 → 展开 → 第三排最左侧黄底黑字 → 预览校验」操作。先应用目标预设，再校验字幕显示。预设通常没有可检索名称，使用当前截图的外观定位最快。

### 4.1 打开正确的样式面板

1. 识别完成后直接单击时间线上的任一字幕片段，打开右侧文字编辑面板；若已自动进入正确面板，则直接继续。不要求此时播放头位于字幕内，也不要求预览先显示白色文字。
2. 确认右侧显示「字幕 / 文本 / 动画…」，进入「文本」→「基础」。若仍显示「画面、音频、变速」或仅显示「属性」，说明选中了视频或多个对象，重新单击时间线字幕片段；只有片段难以选中且预览已有文字时，才双击预览文字。
3. 确认「文本、排列、气泡、花字应用到全部字幕」为勾选状态（本次版本显示青色勾）。先确认此项，再点预设，避免只修改当前一句。

### 4.2 最快找到黄底黑字预设

定位时先查看 [预设样式标注截图](assets/preset-yellow-black-guide.png)：左图圈出折叠状态下的展开箭头，右图圈出展开后第三行最左侧的黄底黑 T。图片由实际剪映界面截图裁切合成并标注，仅作外观与相对位置参考；操作仍以当前截图为准，不从参考图照搬绝对坐标。

![展开箭头与黄底黑字预设位置](assets/preset-yellow-black-guide.png)

1. **微滚即停（切勿滚远）**：在右侧「文本 → 基础」面板中，初始状态下「预设样式」标题其实就在面板中下部（`y ≈ 480~580`），**只需向下轻滚 1~2 格**（使 `预设样式` 标题停在面板中上部 `y ≈ 320~430`）即可看到「预设样式」和前两行字母 T 小方块。**千万不要大幅向下滚动（更不要滚两屏）**，否则会直接滚过「预设样式」进入下方的「混合 / 描边 / 背景 / 发光 / 阴影」区域。若不慎滚过头，向上回滚直到重新看到「预设样式」标题。
2. **先点击底部中央 `▼` 箭头展开第三行**：「预设样式」初始**默认处于折叠状态**，只露出第一行和半截第二行，**第三行默认是隐藏的**。展开按钮不在标题栏右侧，而在两行网格**底部正中央的小向下箭头 `▼`**（悬停提示为「展开」，逻辑坐标约为 `(1513.5, 预设样式标题Y + 114)`）。必须先单击该 `▼` 箭头一次，第三行才会展开显示；不要点击「预设样式」标题，也不要反复点击箭头造成展开后又收起。
3. **直接选择第三行第一个（最左侧）**：展开后寻找 **整个方块是亮黄色实心底，中央是黑色 T** 的图标。位置固定在 **第三行第一个（最左侧，Row 3 Col 1，对应无障碍树第 17 个 `automationstyleIconRepeaterItem`，即 `index 16`）**。先展开再点这个位置，可一步到位，省去盲目滚动与逐个试点。
4. 区分容易误选的图标：第一行中的「黄色 T + 深灰底」会生成黄色文字，不是目标；目标必须是「黄色底 + 黑色 T」。不要凭黄色元素或字母颜色单独判断。
5. 若目标不在上述位置，先确认网格已展开且能看到第三行，再在当前可见网格中按外观查找；确需滚动时只在右侧面板继续滚动，并重新截图定位。不要通过切换字体、花字、气泡或字幕模板寻找这个预设。
6. 根据最新截图点击目标一次，随后读取 `getAXState()`（Antigravity 下使用 `mac_cua.py ax-state` 或重新 `screenshot`）。本次版本预设图标通常不暴露有意义的 AX 名称，坐标点击更直接；坐标必须从当前截图取得，不保存或复用某次操作的绝对坐标。

### 4.3 确认应用成功

1. 应用黄底黑字预设后，再将播放头放在一条字幕片段的中间。选中片段本身不代表播放头已位于片段内，随机跳转可能落在字幕间隙。查看目标图标是否出现选中边框（本次版本为青色），并检查有效字幕时间内的预览：应为 **黑色正文 + 黄色实心底框**。图标选中边框只是辅助证据，预览效果才是结果。
2. 若预览暂未刷新，短暂播放后暂停再检查；不要因为画面未立即变化就反复点预设。
3. 选择另一条相隔较远的字幕，将播放头移到片段中间，短暂播放并暂停，确认同样是黄底黑字。若只有第一句改变，回到「应用到全部字幕」核对勾选，再应用一次目标预设。
4. 应用预设即可，无需再修改字体。保留默认字体、字号、位置、缩放和不透明度，除非用户另有要求，或已在有效字幕时间内确认存在明显遮挡、裁切问题。

### 应用预设后，预览暂时没有字幕时

先检查播放头是否真正落在一条已生成字幕的起止时间内。放大时间线或选中字幕后，将播放头移至片段中间；若仍未显示，短暂播放并暂停，重新观察预览。确认处于字幕有效时间且画面刷新后，再检查轨道可见性。只有发现具体参数异常时才修改，不通过试改字体、字号、位置或透明度排查。

## 5. 导出字幕版 MP4

仅在任务包含导出时执行。

1. 打开右上角「导出」。核对导出的活动时间线和完整时长。
2. **先彻底删除原草稿标题，再填写目标文件名主体**：
   - 「标题」框（`ExportFileNameInput`，`rect=(992, 305, 176, 22)`，中心点 `(1080, 316)`）默认带有 `10月25日 (N)` 等草稿名；**切勿在导出窗口使用 `mouse_drag` 拖拽**（否则会拖动整个无边框导出窗口导致点击脱靶）。
   - 直接单击 `ExportFileNameInput` 中心点 `(1080, 316)`，连续发送 **25 次 `Delete`（退格键）** 将原有标题彻底清空，再通过 `type_unicode` 输入 `<源文件名去扩展名>_字幕版`（格式选择 MP4，由剪映自动添加 `.mp4` 后缀），并读取下方完整路径节点（`desc` 形如 `/.../<源文件名>_字幕版.mp4`）确认标题已完全替换为目标名称、无任何原草稿名残留。
3. 设置「导出至」为目标目录。导出面板的无障碍树通常会显示输出目录路径，利用它核对目录、中文名称与扩展名。
4. 默认保留原始分辨率和已有帧率；不额外启用一键超清、补分辨率、云备份或单独音频导出。

6. 点击「导出」，等待进度完成。只有界面明确显示「导出成功」才算完成，不能把开始导出或进度消失当成成功。
7. 到达导出成功页即停止；不要点击「发布」、分享链接或云端审阅。
8. 最终回复简短说明成功，并提供输出文件的绝对路径链接。若未导出，说明草稿状态及实际草稿名。
